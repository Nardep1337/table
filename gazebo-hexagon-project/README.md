# Альтанка «Стільник» — комплект креслень

Проєкт дерев'яної відкритої альтанки шестикутної форми (вальмовий/шатровий дах), з ескізами готового вигляду.

Відкрийте `altanka-stilnyk.html` у браузері, щоб переглянути повний комплект: план підлоги та фундамент, фасад, план покрівлі, вузли з'єднань, специфікацію матеріалів і ескізи.

## Основні параметри

| Параметр | Значення |
|---|---|
| Форма плану | правильний шестикутник |
| Крок опор (сторона) | 2000 мм |
| Діаметр по кутах | 4000 мм |
| Діаметр по гранях | 3464 мм |
| Площа підлоги | ≈10,4 м² |
| Висота до карниза | 2300 мм |
| Загальна висота | ≈3700 мм |
| Кут нахилу даху | 35° |
| Виліт покрівлі (звис) | 400 мм |
| Каркас | модрина / сосна кл.4 (просочена) |
| Покрівля | бітумна або дерев'яна ґонта |
| Фундамент | 6 кутових стовпчикових опор 400×400×400 мм + 1 центральна 500×500×400 мм |

## Склад комплекту

1. **A1** — План підлоги та фундамент
2. **A2** — Фасад (головний вигляд)
3. **A3** — План покрівлі
4. **A4** — Вузли з'єднань (стійка/обв'язка, крокви/хаб)
5. **A5** — Специфікація матеріалів
6. **A6** — Ескізи готового вигляду

Комплект — довідковий проєкт для будівництва; перед реалізацією перерізи навантажень і вузли кріплення варто узгодити з місцевими будівельними нормами.
